# 动态组卷返回 409 的处理说明

`POST /api/v1/papers/generate` 返回 HTTP 409 时，通常表示组卷规则与题库现有库存冲突，并非网络故障。后端会返回类似：

```text
题库数量不足：题型=SINGLE_CHOICE，难度=EASY，需要=6，可用=3
```

含义是：当前学科、题型、难度及知识点筛选范围下需要 6 道题，但只有 3 道已启用题目可用。

处理方式：
1. 按提示减少该题型数量，或调整难度比例。
2. 检查题目是否属于所选学科，并确认题目状态为启用。
3. 如果填写了知识点 ID，检查 ID 是否正确；当前筛选是精确知识点匹配，留空表示不限制知识点。
4. 必要时新增符合筛选条件的题目。

系统有意不自动降低组卷规则，因为静默减少题数或改变难度比例可能导致总分或考试要求不一致。前端会展示后端返回的具体缺额及处理建议。

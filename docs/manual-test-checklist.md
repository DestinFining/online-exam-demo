# 前端联调与冒烟测试清单

在本机装好依赖并启动后端后，按以下顺序验证：

## 环境启动

- [ ] `backend/` 中 MySQL 和 Redis 已启动，数据库已按 README 初始化。
- [ ] 后端可以启动并监听 `8080`。
- [ ] `frontend/` 执行 `npm install` 后 `npm run build` 成功。
- [ ] `npm run dev` 成功，浏览器可以打开 `http://localhost:5173`。

## 身份认证与权限

- [ ] 用 `student` 登录，能进入学生工作台。
- [ ] 用 `teacher` 登录，能看到题库、试卷、考试、阅卷导航。
- [ ] 用 `admin` 登录，能看到学科、知识点和后台管理入口。
- [ ] 退出登录后访问受保护页面会跳转登录页。
- [ ] 直接调用无权限的后端接口仍返回 403（前端路由守卫不是安全边界）。

## 题库与练习

- [ ] 教师创建单选、多选、判断和填空题。
- [ ] 题目按学科、知识点和题型筛选。
- [ ] 学生开始章节/随机刷题并提交答案。
- [ ] 错题自动收录；收藏与取消收藏生效；按题目 ID 添加/修改笔记。

## 试卷与考试

- [ ] 创建固定试卷并发布。
- [ ] 按题型、难度和知识点动态组卷；库存不足时显示服务端错误。
- [ ] 创建并发布考试，学生在考试时间窗口内可以开始。
- [ ] 作答自动保存，刷新页面后通过服务端尝试恢复。
- [ ] 页面隐藏/显示事件能写入后端日志。
- [ ] 手动交卷后不允许修改，时间到后触发自动交卷。
- [ ] 断网时答案保留在本地，恢复网络后可以继续同步或交卷。

## 阅卷与分析

- [ ] 教师打开提交记录，对简答题/编程题逐题评分。
- [ ] 完成评分后结算成绩并发布。
- [ ] 学生只能查看已发布成绩和自己的答卷。
- [ ] 学情分析能加载统计数值、知识点雷达图和成绩趋势。

> 本检查清单是手动验证步骤，并不表示上述测试已在当前生成环境执行。

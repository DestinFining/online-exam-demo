# 成绩发布和主观题阅卷修复说明

## 修复内容

1. 学生成绩页列出已交卷且处于 `SUBMITTED`、`GRADED` 或 `PUBLISHED` 的考试记录。
2. 成绩状态不是 `PUBLISHED` 时，学生只看到“待阅卷/待发布”，不展示未发布分数。
3. 教师阅卷页自动默认选择一场已发布/已结束考试，避免页面初始化始终为空。
4. 打开教师阅卷详情时，为历史提交中缺失的试卷题目补建空答题记录，确保简答题、编程题至少出现在评分列表中。
5. 结算时不再静默跳过缺失的主观题答案记录。
6. 前端将成绩结算、发布、详情加载的实际错误显示给用户，不再吞掉异常。

## 教师标准流程

学生交卷 → 在“阅卷与成绩”选择考试 → 打开该考生的“阅卷详情” → 批改所有简答题和编程题 → 点击“结算成绩” → 点击“发布成绩”。

注意：含有简答题或编程题的考试，学生提交后状态为 `SUBMITTED`，需要教师完成主观题评分并发布后才显示最终成绩。

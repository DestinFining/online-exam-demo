# 刷题启动接口 400 修复说明

## 原因
Vue 的可清空题型/难度选择框未选择时会发送 `type: ""` 和 `difficulty: ""`。后端原代码把空字符串视为已提供的题型，因而返回“不支持的题型”并产生 400。

## 修复
- 前端请求封装把空题型/难度转换为 `undefined`，JSON 请求中不再传这两个筛选字段。
- 后端 `PracticeService.start` 也将 null、空字符串和纯空白字符串统一视为无筛选条件。
- 对非空非法题型/难度仍返回参数错误。
- 如果筛选后确实没有已启用题目，返回清晰的“没有符合条件的练习题”业务提示。

## 验证
静态检查确认请求封装已标准化空筛选值，后端组卷查询使用标准化后的筛选条件。仍建议本地执行 `mvn clean compile`，并在浏览器选择“全部题型/全部难度”验证 `/api/v1/practice/start`。

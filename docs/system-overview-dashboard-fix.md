# 管理员工作台与系统概览页面分离

## 问题原因
路由 `/dashboard` 与 `/system` 原先都指向 `DashboardView.vue`，所以管理员在“工作台”和“系统概览”看到的是同一个页面。

## 修复方案
- `/dashboard` 继续显示工作台：欢迎信息、常用任务、考试动态。
- `/system` 单独显示 `SystemOverviewView.vue`：平台资源数量、管理模块入口和统计口径说明。
- 工作台角色识别改为管理员优先，避免多角色账号按角色数组顺序被误显示成教师工作台。
- 系统概览数字通过现有管理 API 获取；请求失败时显示“—”，不展示模拟数据。

## 验证建议
登录管理员账号后分别打开“工作台”和“系统概览”，确认两个路由的页面内容、标题和布局明显不同；使用“刷新数据”检查统计指标是否更新。

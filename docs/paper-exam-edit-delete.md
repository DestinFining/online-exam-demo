# 试卷与考试管理增强

## 试卷管理

- 草稿及已发布试卷均可编辑名称、学科、时长、固定题目及分值，或修改动态组卷的题型数量、每题分值、难度比例和知识点范围；已归档试卷不可修改。
- 试卷列表支持多选批量删除，单次最多 100 份。
- 被任意考试（包括已归档考试）引用的试卷禁止删除。批量删除按事务整体执行，只要其中一份试卷被引用，本次所有删除都会被拒绝。
- 试卷编辑与删除都校验创建者权限；管理员可以管理全部试卷。已发布试卷仅在关联考试全部尚未开始且没有答卷时允许修改；已开始、已结束/归档或已有答卷时，后端拒绝修改以保护考试历史。

## 考试管理

- 草稿考试可编辑；已发布但尚未开始、且不存在作答记录的考试也可修改。考试开始后禁止修改，防止影响考生作答和成绩。
- 指定考生模式支持编辑已有考生 ID，保存时会在事务内重建考生范围。
- 对考试结束时间已到的已发布考试，提供“删除”操作。为保护答卷、成绩、阅卷记录和考试行为日志，该操作采用归档式删除：状态置为 `ARCHIVED`，默认列表隐藏，用户可以通过“已归档”筛选查看历史记录。
- 后端会再次校验考试确实已经结束及创建者权限，不能仅靠前端按钮控制。

## 新增 / 调整接口

- `PUT /api/v1/papers/{id}`：编辑草稿或安全条件下的已发布试卷，并验证所有权及考试历史约束。
- `POST /api/v1/papers/batch-delete`：批量删除未被考试引用的试卷，JSON 请求体为 `{ "ids": [1, 2, 3] }`。
- `GET /api/v1/exams/{id}/candidates`：读取可编辑考试的指定考生 ID。
- `PUT /api/v1/exams/{id}`：更新草稿考试或尚未开始且无作答记录的已发布考试。
- `DELETE /api/v1/exams/{id}`：将已结束考试归档，保留历史数据。

## 验证

当前执行环境无 Maven，也没有安装前端依赖，已执行仓库内静态一致性检查和 TypeScript 脚本语法转译检查；需在本机继续运行 `mvn clean test` 与 `npm run build`。


## 已发布试卷的编辑限制（补充）

已发布的试卷也显示“编辑”按钮。草稿试卷可以直接编辑；已发布试卷在没有关联考试，或其关联考试均尚未开始且没有答卷时允许编辑。编辑已发布试卷时会提示：更新将影响尚未开始的关联考试。

为保护考试历史，若关联考试已开始、已结束/归档，或任意关联考试已有答卷，后端返回 HTTP 409 并拒绝保存。已归档试卷仍不可编辑。权限继续遵循原有 RBAC：教师只能编辑自己创建的试卷，管理员可以编辑所有试卷。
